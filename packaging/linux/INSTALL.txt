MIDGARD FOR LINUX

Python is already embedded in this package.

Install for the current user:

    bash install-midgard.sh

Install without launching:

    bash install-midgard.sh --no-launch

The installer displays progress and stores its log at:

    ~/.local/state/midgard/installer.log

Settings and downloaded models are stored outside the application directory so
future releases can update Midgard without deleting personal data.
