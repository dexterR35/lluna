# Keyboard shortcuts

| Action | Shortcut |
|---|---|
| New / Open / Save / Save As | Ctrl/Cmd+N / O / S / Shift+S |
| Undo / Redo | Ctrl/Cmd+Z / Shift+Z |
| Copy / Cut / Paste / Duplicate | Ctrl/Cmd+C / X / V / D |
| Select all / Delete | Ctrl/Cmd+A / Delete |
| Find or add node | Tab |
| Run workflow | Ctrl/Cmd+Enter |
| Fit workflow | F |
| Preferences | Ctrl/Cmd+, |
| Full screen | F11 |

Native menus display platform accelerators. Canvas-only keys are ignored while focus is in an input, textarea, or select. Escape closes dialogs/menus; run stop remains an explicit command to avoid destructive accidental cancellation.
